# Bank-Loan-Analysis
Bank Loan Analysis using SQL and Power BI

Project Overview

This project analyzes bank loan data using SQL Server and Power BI to gain insights into loan applications, funded amounts, repayment performance, good loans vs bad loans, and customer trends.

Tools Used

- SQL Server (SSMS)
- Power BI
- Excel

Project Files

- Dataset CSV file
- SQL Queries
- Power BI Dashboard
- Query Documentation
- Dashboard Screenshots

Key Insights

- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Good Loan vs Bad Loan Analysis
- Interest Rate Analysis
- State-wise Loan Analysis

Dashboard Features

- Interactive filters
- KPI cards
- Loan status analysis
- Monthly trends
- Detailed loan reports
